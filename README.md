# МЫ РЯДОМ — PWA 0.1

Демонстрационный PWA-прототип. Содержит четыре пользовательских маршрута, возрастные группы, 12 тематических модулей, шесть интерактивных ситуаций, материалы для взрослых, справочник помощи, локальный прогресс и офлайн-кэш.

## Запуск
PWA и Service Worker работают на HTTPS или localhost. Для локального запуска выполните `python -m http.server 8080` в папке проекта и откройте `http://localhost:8080`.

Для публикации загрузите файлы в GitHub и включите GitHub Pages. Для репозитория с публикацией не из корня проверьте относительные пути и `scope` в manifest.

## Ограничения
Версия 0.1 — демонстрационный прототип, не прошедший экспертную, юридическую и пользовательскую апробацию. Не является официально одобренной Минпросвещения программой и не заявляет о подтверждённом соответствии ФГОС. Перед пилотом обязательны экспертиза контента, проверка контактов, аудит безопасности и согласование со школой.

## Приватность
Нет аккаунтов, чатов, пользовательских жалоб, загрузки файлов, аналитики или серверного хранения историй. Локально хранится только список ID завершённых учебных модулей.
