# Версия 1.18 — надёжный сброс прогресса и офлайн-навигация

## Исправления
- Кнопка сброса на главной странице очищает основной прогресс и локальные данные маршрута ученика: завершённые направления, черновики ответов/заданий и сохранённый текущий этап.
- Перед сбросом показывается предупреждение, что действие нельзя отменить. Удаляются только ключи учебного прогресса проекта; остальные данные сайта не очищаются.
- Service Worker ищет закэшированные ресурсы без учёта query-параметров. Поэтому `lesson-library.html?mode=student` может использовать закэшированную `lesson-library.html` и открываться офлайн после первой загрузки.
- Версия кэша обновлена до `my-ryadom-1.18`.

## Проверки
- Синтаксис JavaScript и целостность ZIP проверяются при сборке.
- Проверка офлайн-перехода в этом релизе выполнена на уровне логики Service Worker; требуется повторная ручная проверка на iPhone и Android после публикации.

## Ограничения
Прогресс остаётся локальным для браузера/устройства. Очистка данных сайта, приватный режим или удаление приложения могут привести к потере данных.
